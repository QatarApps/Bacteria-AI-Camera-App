حزمة تشغيل نموذج البكتيريا بالكاميرا - نموذج بحثي تجريبي

الملفات:
- bacteria_classifier_torchscript.pt : النموذج المدرب
- bacteria_labels.txt : أسماء الفئات
- camera_app.py : برنامج الكاميرا
- requirements.txt : المكتبات المطلوبة
- RUN_WINDOWS.bat : تشغيل على Windows

طريقة التشغيل:
1) فك ضغط الملف في مجلد واحد.
2) يجب تثبيت Python 3 على الكمبيوتر.
3) وصّل الكاميرا (أو استخدم كاميرا اللابتوب).
4) شغّل RUN_WINDOWS.bat.
5) في أول تشغيل سيتم تثبيت المكتبات ثم تشغيل الكاميرا.
6) اضغط Q لإغلاق البرنامج.

الأحمر = النموذج صنف الصورة Pseudomonas aeruginosa أو Staphylococcus aureus.
الأخضر = إحدى فئات المقارنة/العينات السالبة.

تنبيه:
هذا نموذج بحثي تجريبي لتصنيف الصور، وليس جهاز تشخيص طبي معتمد.
أداء النموذج قد يتغير بشدة مع كاميرا/مجهر/إضاءة تختلف عن صور التدريب.
